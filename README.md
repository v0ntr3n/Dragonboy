# Dragonboy Unity Project - [EN](./README_EN.md) | VI
Project Unity Mod Cộng Đồng (Dự án đang trong giai đoạn phát triển).

Hướng dẫn xây dựng thêm tính năng cho bản mod: https://youtu.be/9sCof2eQH3Q

Discord hỏi đáp: https://discord.gg/zdvBdVxRh6

## Biên dịch
- **Game (`GameProject/DragonBoy250`)**: Sử dụng Unity Editor phiên bản `6000.3.9f1` (hoặc chạy `./GameProject/build.sh` trên macOS) để biên dịch game.
- **QLTK (`AccountManager/AccountManager.xcodeproj`)**: Sử dụng Xcode trên macOS để biên dịch ứng dụng quản lý tài khoản (Account Manager).
- **Windows x64 CI**: Xem hướng dẫn tự động biên dịch bản Windows x64 qua GitHub Actions tại [docs/WINDOWS_CI.md](./docs/WINDOWS_CI.md).

Nếu bạn không tự biên dịch được, bạn có thể tải xuống các phiên bản cộng đồng đã biên dịch trước đó tại [Dragonboy-CommunityMod-Builds](https://github.com/ElectroHeavenVN/Dragonboy-CommunityMod-Builds) host bởi [@ElectroHeavenVN](https://github.com/ElectroHeavenVN).
